# PixelForge

Пиксель-арт редактор для Windows на Electron: рисует друг, рисуете вы — без установки и подписок.

![Electron](https://img.shields.io/badge/Electron-45-47848F?logo=electron&logoColor=white)
![Windows](https://img.shields.io/badge/Windows-x64-0078D6?logo=windows&logoColor=white)

## Возможности

- Холст от 1×1 до 512×512, пресеты 8 / 16 / 24 / 32 / 48 / 64 / 128 для мелких спрайтов
- Инструменты: карандаш, ластик, заливка, пипетка (пипетка ещё и по Alt+клик)
- Сетка по каждому пикселю с усилением каждые 8 клеток, включается Ctrl+G
- Зум ×1–×64 колесом мыши, панорама средней кнопкой или пробелом
- Палитра из 24 цветов, HEX-ввод, системный выбор цвета, недавние цвета
- Отмена/повтор до 120 шагов, отражение по горизонтали и вертикали
- Экспорт PNG с увеличением ×1…×16 (прозрачность сохраняется)
- Проект сохраняется в JSON и открывается обратно
- Шахматка прозрачности, портативная сборка одним exe

## Скачать

Готовый файл — в разделе [Releases](../../releases): `PixelForge-1.0.0-portable.exe`, около 100 МБ.
Установка не нужна: запустили — рисуете. Windows может показать предупреждение SmartScreen, потому что файл не подписан сертификатом; «Подробнее» → «Выполнить в любом случае».

## Горячие клавиши

| Клавиши | Действие |
| --- | --- |
| `B` / `E` / `G` / `I` | карандаш / ластик / заливка / пипетка |
| `Alt` + клик | взять цвет под курсором |
| `Ctrl+Z`, `Ctrl+Shift+Z` | отменить, повторить |
| `Ctrl+N` | разрешение холста (новый холст) |
| `Ctrl+S` / `Ctrl+O` | сохранить / открыть проект |
| `Ctrl+E` | экспорт PNG |
| `+` / `−`, `0` | зум, вписать в окно |
| `Ctrl+G` | сетка |
| `Пробел` + перетаскивание | панорама |

Правая кнопка мыши стирает, минуя выбор инструмента.

## Сборка из исходников

Нужен Node.js 18+.

```bash
npm install
npm start          # запуск в режиме разработки
npm run icon       # пересобрать build/icon.ico
npm run dist       # portable exe в dist/
```

## Устройство проекта

| Файл | Назначение |
| --- | --- |
| `main.js` | окно приложения, диалоги сохранения/открытия файлов |
| `preload.js` | мост `window.api` между интерфейсом и системой |
| `index.html`, `style.css` | интерфейс редактора |
| `renderer.js` | холст, инструменты, история, экспорт |
| `tools/make-icon.js` | генератор иконки без внешних зависимостей |

Данные рисунка хранятся в `Uint8ClampedArray` (RGBA), история — копии буфера, поэтому отмена не требует отдельного формата документа.
